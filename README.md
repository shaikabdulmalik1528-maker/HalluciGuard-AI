# 🛡️ HalluciGuard AI

### Not All That Is Fluent Is Factual — Investigating Hallucinations of Large Language Models

HalluciGuard AI is an academic research project focused on investigating factual hallucinations in Large Language Models (LLMs), examining how fluent AI-generated responses can sometimes contain inaccurate or misleading information.

## 🎯 Project Objective

To investigate factual reliability in Large Language Models and explore different prompting strategies for analyzing AI-generated responses.

## 🔬 Research Approach

The research explores four prompting paradigms:

- Zero-Shot Prompting
- Few-Shot Prompting
- Chain-of-Thought Prompting
- Role-Based Prompting

## ✨ Project Highlights

- AI hallucination investigation
- Comparative prompt analysis
- Research-oriented interface
- AI-generated response analysis
- Results visualization and reporting
